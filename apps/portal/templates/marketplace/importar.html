Cadastrar automação

Cole o automation.yaml da automação. É o contrato de extensão da plataforma: nenhuma alteração no código do Órbita é necessária para registrar uma automação nova — nem para uma escrita em outra linguagem.

Como funciona

  1. O manifesto é validado contra o contrato. Campo desconhecido é recusado, não ignorado — manifesto com erro de digitação que "funciona pela metade" é pior do que manifesto recusado.
  2. A automação é criada ou atualizada pelo identificador. Reimportar não duplica, o que permite ao pipeline da automação rodar a importação a cada release.
  3. Os gatilhos são substituídos pelos declarados: um agendamento retirado do arquivo deixa de disparar.
  4. Permissões concedidas na tela de acesso sobrevivem à reimportação. Elas são decisão operacional, e um git push não deve revogá-las.

Exemplo mínimo

apiVersion: orbita.inrh/v1
kind: Automacao
metadata:
  nome: meu-relatorio
  titulo: Meu relatório
  versao: 1.0.0
  categoria: relatorios
  descricao: >-
    Descrição com ao menos 40 caracteres,
    exigida para poder publicar.
  responsavel_tecnico: Equipe X
  responsavel_negocio: Área Y
spec:
  tipo: batch
  imagem: local/meu-relatorio
  entrypoint: [python, -I, main.py]
  recursos:
    cpus: 0.5
    memoria_mb: 512
    timeout_segundos: 300
  parametros:
    - nome: competencia
      rotulo: Competência
      tipo: mes
      obrigatorio: true
  gatilhos:
    - tipo: manual
  permissoes:
    - escopo: todos
      nivel: executar
